Frontend to Backend Export Specifications

Data Payload Structure

When the student submits this form, the frontend gathers all inputs into a clean JavaScript Object with the following properties:

  • class (string): Selected grade/exam level.
  • subject (string): Selected academic subject.
  • chapter (string): Selected chapter name.
  • topic (string): Optional custom topic tag.
  • questionText (string): Detailed question description.
  • doubtFocus (string): Selected focus (e.g., "Full Step-by-Step Solution").
  • photo (object | null): Contains base64 image string, fileName, and mimeType.
  • preferences (object): Preferred language, solution format, and urgency level.
